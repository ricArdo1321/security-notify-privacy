Política de privacidad — Security Notify WhatsApp

Última actualización: 28 de septiembre de 2026

Qué datos se usan

La aplicación accede, con autorización OAuth del propietario, únicamente a su propia cuenta de Gmail. Lee el asunto, el remitente y la fecha de los correos que tienen la etiqueta Seguridad, y agrega la etiqueta Seguridad/Notificado a los que ya avisó.

Para qué se usan

Esos tres datos se envían, mediante la API de WhatsApp Business de Meta, como un mensaje de aviso a los números de teléfono que el propio propietario configuró. No se leen ni se envían los cuerpos ni los adjuntos de los correos.

Almacenamiento y terceros

La aplicación no guarda datos de correos en ninguna base de datos. No vende, no comparte ni transfiere datos a terceros, salvo el envío a WhatsApp descrito arriba. No usa los datos para publicidad ni para entrenar modelos de inteligencia artificial.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.
